民宿管家端

集成房态入住管理与营业分析，助力高效服务与精准运营。

C 端项目
作品封面 · 房态主页 / 首页 / 录单 1500 × 3248 · 真实产品截图
PROJECT

项目背景

面向民宿现场管理的运营助手 App，支持实时房态查看、入住 / 续住 / 离店操作及分店营业数据分析，帮助管家高效处理日常接待与现场运营，辅助管理者掌握关键指标、优化运营策略。

VALUE

产品卖点

实时房态 高效接待 数据洞察 精准运营
HOMEPAGE

首页

门店与时间维度

展示当前门店信息，并提供日、周、月、年等多维度时间筛选。

关键经营指标

聚合展示总营业额、总订单数、间夜数及入住率等关键经营指标。

待办与快捷入口

直观呈现今明两日待入住 / 待离店单量，并提供资产管理快捷入口。

ORDER

录单

管家直观选择对应房态，快速录入客户订单信息，确认后即可完成订单录入。
